# বাংলা শুদ্ধ-অশুদ্ধ কুইজ (১০ নম্বর)

## ফাইল সমূহ:

### C# ফাইল:
- **QuizQuestion.cs** - প্রশ্নের মডেল ক্লাস
- **QuizService.cs** - কুইজ লজিক এবং স্কোর ক্যালকুলেশন
- **Program.cs** - কনসোল অ্যাপ্লিকেশন
- **BanglaQuiz.csproj** - প্রজেক্ট ফাইল

### HTML ফাইল:
- **index.html** - ইন্টারঅ্যাক্টিভ ওয়েব কুইজ (JavaScript সহ)

## কিভাবে চালাবেন:

### C# কনসোল অ্যাপ:
```bash
dotnet run
```

### HTML ওয়েব কুইজ:
`index.html` ফাইলটি ব্রাউজারে খুলুন

## বৈশিষ্ট্য:
- ৫টি প্রশ্ন × ২ নম্বর = মোট ১০ নম্বর
- শুদ্ধ/অশুদ্ধ উত্তর
- স্বয়ংক্রিয় স্কোর ক্যালকুলেশন
- সঠিক উত্তর এবং ব্যাখ্যা প্রদর্শন
